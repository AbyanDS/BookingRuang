1.1 ARSITEKTUR SISTEM
----------------------
Sistem ini dibangun dengan arsitektur Model-View-Controller (MVC) sederhana:

A. STRUKTUR FOLDER:
   /PlsworkUKK/
   ├── admin/              (Halaman admin & petugas)
   ├── user/               (Halaman user)
   ├── petugas/            (Halaman petugas)

(`booking_ruangan`.`booking`, CONSTRAINT `booking_ibfk_1`

- Mengakibatkan nilai ruangan_id kosong atau undefined

SOLUSI:

2. Tambahkan validasi room existence sebelum insert:
   ```php
   $check_room = "SELECT id FROM ruangan WHERE id = '$ruangan_id' AND status = 'tersedia'";
   $result_check = mysqli_query($conn, $check_room);
   if (mysqli_num_rows($result_check) == 0) {
       $error = 'Ruangan tidak valid atau tidak tersedia!';
   }
   ```

   ```php
   $ruangan_id_safe = mysqli_real_escape_string($conn, $ruangan_id);
   ```

ERROR #2: UNION Query Column Mismatch
--------------------------------------
PESAN ERROR:
"Terjadi kesalahan saat memuat data"
"The used SELECT statements have a different number of columns"

PENYEBAB:
- Query UNION untuk gabungkan jadwal_ruangan dan booking
- Jumlah kolom SELECT tidak sama:
  * jadwal_ruangan: 8 kolom
  * booking: 10 kolom
- Nama kolom tidak konsisten

SOLUSI:
1. Samakan jumlah kolom di kedua SELECT (10 kolom):
   ```sql
   -- Jadwal tetap
   SELECT j.waktu_mulai, j.waktu_selesai, j.kegiatan, j.keterangan,
          r.nama_ruangan, r.lokasi, j.penanggung_jawab,
          'jadwal' as source_type, NULL as tanggal_booking, NULL as booking_status
   FROM jadwal_ruangan j ...
   
   -- Booking
   SELECT TIME_FORMAT(b.waktu_mulai, '%H:%i:%s') as waktu_mulai,
          TIME_FORMAT(b.waktu_selesai, '%H:%i:%s') as waktu_selesai,
          b.keperluan as kegiatan, b.keterangan,
          r.nama_ruangan, r.lokasi, u.nama_lengkap as penanggung_jawab,
          'booking' as source_type, b.tanggal_booking, b.status as booking_status
   FROM booking b ...
   ```
2. Gunakan UNION ALL untuk better performance
3. Tambahkan TIME_FORMAT untuk konsistensi format waktu

STATUS: ✓ RESOLVED

```javascript
function validateBookingForm() {
    const tanggal = document.getElementById('tanggal_booking').value;
    const waktuMulai = document.getElementById('waktu_mulai').value;
    const waktuSelesai = document.getElementById('waktu_selesai').value;
    
    // Validate date not in past
    const today = new Date().toISOString().split('T')[0];
    if (tanggal < today) {
        alert('Tanggal booking tidak boleh di masa lalu!');
        return false;
    }
    
    // Validate time if today
    if (tanggal === today) {
        const now = new Date();
        const startTime = new Date(tanggal + ' ' + waktuMulai);
        if (startTime <= now) {
            alert('Waktu tidak boleh di masa lalu!');
            return false;
        }
    }
    
    // Validate duration minimum 1 hour
    const start = new Date('2000-01-01 ' + waktuMulai);
    const end = new Date('2000-01-01 ' + waktuSelesai);
    const duration = (end - start) / (1000 * 60 * 60);
    
    if (duration < 1) {
        alert('Durasi booking minimal 1 jam!');
        return false;
    }
    
    return true;
}
```

   error_reporting(E_ALL);
   ini_set('display_errors', 0);
   ini_set('log_errors', 1);

3. Enable HTTPS/SSL di Apache:
   - Install SSL certificate
   - Update .htaccess untuk force HTTPS

4. Set file permissions:
   - Folder: 755
   - File: 644
   - Uploads folder: 775

5. Setup cron job untuk auto-cleanup (optional):
   0 0 * * * php /path/to/config/auto_cleanup_completed_bookings.php

6. Setup automated backup database (daily):
   0 2 * * * mysqldump -u user -p booking_ruangan > backup_$(date +\%Y\%m\%d).sql


LAMPIRAN E: PANDUAN PENGGUNAAN
-------------------------------

E.1 UNTUK USER
--------------
1. Register akun baru atau login dengan akun existing
2. Pilih menu "Booking" untuk membuat booking baru
3. Ikuti 4 langkah booking: Pilih Ruangan → Tanggal/Waktu → Keperluan → Review
4. Submit booking dan tunggu approval dari admin/petugas
5. Cek status booking di menu "Riwayat"
6. Lihat booking yang sudah approved di menu "List Booking"
7. Lihat jadwal lengkap di menu "Jadwal Ruangan"


E.2 UNTUK ADMIN/PETUGAS
-----------------------
1. Login dengan akun admin/petugas
2. Kelola data ruangan di menu "Ruangan"
3. Kelola jadwal tetap di menu "Jadwal"
4. Review dan approve/reject booking di menu "Booking"
5. Lihat statistik dan export laporan di menu "Laporan"
6. Monitor aktivitas di menu "History"
7. Kelola user (khusus admin) di menu "Users"
8. Handle reset password request di menu "Password Reset"


E.3 FITUR KHUSUS
----------------
1. REAL-TIME FILTER: Filter jadwal berdasarkan ruangan dan hari tanpa refresh
2. AUTO-CLEANUP: Booking completed otomatis hilang dari jadwal
3. BUSY TIMES: Warning visual untuk waktu yang sudah terpakai
4. COUNTDOWN: Timer countdown ke waktu mulai booking
5. MOBILE RESPONSIVE: Akses sistem dari smartphone dengan UI optimized
6. EXPORT: Export laporan ke Excel atau Print ke PDF
7. RESET PASSWORD: System reset password dengan token dan approval admin


LAMPIRAN F: TROUBLESHOOTING
----------------------------

F.1 ERROR CONNECTION REFUSED
-----------------------------
MASALAH: "Connection refused" atau tidak bisa akses database
SOLUSI:
- Pastikan MySQL service running
- Cek kredensial database di config/database.php
- Pastikan database 'booking_ruangan' sudah dibuat


F.2 ERROR 500 INTERNAL SERVER
------------------------------
MASALAH: Halaman blank atau error 500
SOLUSI:
- Enable error display: ini_set('display_errors', 1);
- Cek error log di XAMPP/logs/error.log
- Pastikan semua file PHP syntax benar
- Cek file permission (uploads folder)


F.3 FOTO TIDAK MUNCUL
----------------------
MASALAH: Foto ruangan atau profile tidak ditampilkan
SOLUSI:
- Cek folder uploads/ ada dan memiliki write permission
- Pastikan path foto di database benar
- Cek file foto ada di folder uploads/


F.4 AJAX NOT WORKING
--------------------
MASALAH: Filter atau load data tidak jalan
SOLUSI:
- Cek console browser untuk error JavaScript
- Pastikan jQuery loaded
- Cek network tab untuk response AJAX
- Pastikan JSON response valid (gunakan JSONLint)


F.5 SESSION TIMEOUT
-------------------
MASALAH: Sering logout otomatis
SOLUSI:
- Increase session timeout di php.ini:
  session.gc_maxlifetime = 86400 (24 hours)
- Clear browser cookies
- Cek server time sync
